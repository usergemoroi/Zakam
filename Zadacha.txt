Сделай в моем репозитории на GitHub инжектор с рут-правами для Android (Magisk/KernelSU). Дамп с сигнатурами и офсетами лежит в репозитории. Инжектор должен запрашивать суперпользователя, внедрять в процесс Standoff 2 ELF-библиотеку с читовым GUI. Единый ключ активации: 73D37C08. При запуске — окно ввода ключа, после проверки — автоматический переход в игру и инжекция. GUI современный с ником tg.Reward, темный/черный стиль с плавными анимациями, toggle-переключатели, слайдеры для настроек aimbot (FOV, smooth), ESP (боксы, скелеты, дистанция), визуалы (No Flash, яркие модели). Чит-меню должно скрываться по горячей клавише (например, свайп по экрану). Код защиты: проверка целостности библиотеки, обфускация строк, анти-отладка.
