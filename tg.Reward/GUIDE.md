## 🚀 Первый запуск

### Шаг 1: Установка приложения
```
1. Скачайте tg.Reward.apk
2. Включите "Неизвестные источники" в настройках Android
3. Установите APK файл
4. Запустите приложение
```

### Шаг 2: Предоставление разрешений
При первом запуске приложение запросит:
- ✅ Отображение поверх других окон (SYSTEM_ALERT_WINDOW)
- ✅ Доступ к интернету (INTERNET)
- ✅ Запись на устройство (WRITE_EXTERNAL_STORAGE)

**Важно:** Предоставьте все разрешения для корректной работы!

## 🔐 Система аутентификации

### Экран входа

```
┌────────────────────────────────────┐
│                                    │
│         🔥 tg.Reward 🔥           │
│                                    │
│    Система аутентификации          │
│                                    │
│  ┌──────────────────────────────┐ │
│  │ Введите ключ...              │ │
│  └──────────────────────────────┘ │
│                                    │
│  ┌──────────────────────────────┐ │
│  │         СТАРТ                │ │
│  └──────────────────────────────┘ │
│                                    │
└────────────────────────────────────┘
```

### Процесс аутентификации
1. **Ввод ключа:** `73D37C08`
   - Вводите символы точно как указано
   - Регистр не важен
   
2. **Активация кнопки:**
   - При правильном ключе кнопка загорается красным
   - Появляется анимация пульсации
   
3. **Запуск:**
   - Нажмите красную кнопку "СТАРТ"
   - Произойдет плавный переход
   - Автоматический запуск SO2

### 🔑 Ключ супер-пользователя
```
Мастер-ключ: 73D37C08
```

## 🧭 Навигация по меню

### Структура меню
Меню tg.Reward организовано в **категории**:

```
📁 tg.Reward Menu
├── 📂 Visual ESP
│   ├── Player ESP
│   ├── Box ESP
│   ├── Health Bar
│   └── ...
├── 📂 Aim Assist
│   ├── Silent Aim
│   ├── Triggerbot
│   └── ...
├── 📂 Movement
├── 📂 Weapon Mods
├── 📂 Player Mods
├── 📂 World Mods
├── 📂 Skin Changer
├── 📂 Anti Aim
├── 📂 Misc
└── 📂 Settings
```

### Типы элементов меню

#### 🔘 Toggle (Переключатель)
```
[✓] Player ESP  ← Включено (красная галочка)
[ ] Box ESP     ← Выключено
```
- Нажмите для включения/выключения
- Красная галочка = активно

#### 📊 SeekBar (Ползунок)
```
FOV Size: [====|--------] 120°
         1               360
```
- Перетащите ползунок для настройки
- Значение отображается справа

#### ⌨️ InputValue (Ввод значения)
```
Smooth Aim: [10]
```
- Нажмите для ввода числа
- Используйте клавиатуру

#### 🔴 Button (Кнопка)
```
[Apply Skins]
```
- Нажмите для выполнения действия
- Мгновенный эффект

## 🎮 Описание функций

### 👁️ Visual ESP

#### Player ESP
- **Описание:** Отображает контуры игроков через стены
- **Цвета:** 
  - Красный = враги
  - Зеленый = союзники
- **Применение:** Видеть позиции врагов

#### Box ESP
- **Описание:** Рамки вокруг игроков
- **Виды:** 2D/3D боксы
- **Применение:** Быстрое определение позиции

#### Health Bar
- **Описание:** Полоска здоровья над игроками
- **Цвета:** Зеленый → Желтый → Красный
- **Применение:** Видеть HP противников

#### Distance ESP
- **Описание:** Расстояние до игроков в метрах
- **Формат:** "50m"
- **Применение:** Оценка дистанции для стрельбы

#### Skeleton ESP
- **Описание:** Скелет игроков
- **Вид:** Линии костей
- **Применение:** Видеть позу игрока

#### Radar
- **Описание:** Мини-радар на экране
- **Вид:** Круговая диаграмма
- **Применение:** Отслеживание позиций

#### Chams
- **Описание:** Яркая подсветка моделей
- **Эффект:** Светящиеся игроки
- **Применение:** Видеть сквозь объекты

#### Hit Markers
- **Описание:** Индикаторы попаданий
- **Вид:** Крестики при попадании
- **Применение:** Подтверждение хита

---

### 🎯 Aim Assist

#### Silent Aim
- **Описание:** Невидимая корректировка прицеливания
- **Работа:** Автоматическое наведение на цель
- **Применение:** Точные выстрелы без видимого движения мыши

#### Triggerbot
- **Описание:** Автоматическая стрельба при наведении
- **Работа:** Выстрел когда прицел на враге
- **Применение:** Мгновенная реакция

#### FOV Circle
- **Описание:** Круг зоны прицеливания
- **Настройка:** 1-360 градусов
- **Применение:** Визуализация зоны aim assist

#### Auto Stop
- **Описание:** Автоматическая остановка при стрельбе
- **Эффект:** Улучшенная точность
- **Применение:** Стрельба стоя для меньшего разброса

#### Auto Scope
- **Описание:** Автоматическое использование прицела
- **Работа:** Прицеливание при зажатии ЛКМ
- **Применение:** Быстрый scope

#### Smooth Aim
- **Описание:** Плавное наведение
- **Настройка:** 1-100 (скорость)
- **Применение:** Естественное прицеливание

---

### 🏃 Movement

#### Third Person
- **Описание:** Вид от третьего лица
- **Камера:** Позади игрока
- **Применение:** Лучший обзор

#### Noclip
- **Описание:** Прохождение сквозь стены
- **Управление:** Стандартные клавиши
- **Применение:** Разведка карты

#### Bunny Hop
- **Описание:** Автоматические прыжки
- **Эффект:** Постоянные прыжки
- **Применение:** Сложная цель

#### Speed Hack
- **Описание:** Увеличение скорости передвижения
- **Множитель:** 1-10x
- **Применение:** Быстрое перемещение

#### Air Jump
- **Описание:** Прыжки в воздухе
- **Количество:** Неограниченно
- **Применение:** Достижение высоких мест

#### High Jump
- **Описание:** Высокие прыжки
- **Высота:** ~3x обычного
- **Применение:** Преодоление препятствий

#### Fly Mode
- **Описание:** Полет
- **Управление:** Прыжок = вверх, Присесть = вниз
- **Применение:** Свободное перемещение

### 🔫 Weapon Mods

#### Infinite Ammo
- **Описание:** Бесконечные патроны
- **Эффект:** Нет перезарядки
- **Применение:** Непрерывная стрельба

#### No Recoil
- **Описание:** Отсутствие отдачи
- **Эффект:** Прицел не двигается
- **Применение:** Точная стрельба

#### Rapid Fire
- **Описание:** Увеличенная скорострельность
- **Множитель:** ~2-3x
- **Применение:** Больше урона в секунду

#### Fast Knife
- **Описание:** Быстрые удары ножом
- **Скорость:** ~3x быстрее
- **Применение:** Мгновенные убийства

#### Anti Grenade
- **Описание:** Отражение гранат
- **Эффект:** Гранаты не наносят урон
- **Применение:** Защита от взрывчатки

#### Friendly Fire
- **Описание:** Урон союзникам
- **Внимание:** Используйте осторожно!
- **Применение:** Тролинг команды

#### One Shot Kill
- **Описание:** Убийство с одного выстрела
- **Эффект:** Любое оружие = инста-килл
- **Применение:** Мгновенные убийства

### 🎨 Skin Changer

#### Процесс замены скинов:
```
1. Включите "Enable Skin Changer"
2. Введите Knife ID (например: 12)

5. Перезапустите раунд
```

#### Популярные ID:
- **Ножи:** 1-50
- **Скины:** 1-500

## 💡 Советы и рекомендации

### ✅ Рекомендуется использовать
- Visual ESP для новичков
- Aim Assist для улучшения навыков
- Movement для разведки

### ⚠️ Используйте осторожно
- God Mode (очевидный читинг)
- Speed Hack выше 3x (заметен)
- Spinbot (может привлечь внимание)

### ❌ Не рекомендуется
- Friendly Fire в серьезных матчах
- Все моды одновременно (лаги)
- Использование на основном аккаунте

## 🔧 Решение проблем

### Меню не появляется
```
1. Проверьте разрешение SYSTEM_ALERT_WINDOW
2. Перезапустите SO2
3. Переустановите приложение
```

### Функции не работают
```
1. Убедитесь что SO2 запущен
2. Проверьте что галочки включены
3. Попробуйте выключить/включить функцию
```

### Приложение вылетает
```
1. Очистите кеш SO2
2. Освободите RAM (закройте приложения)
3. Перезагрузите устройство
```

### Ключ не принимается
```
1. Проверьте правильность ввода: 73D37C08
2. Удалите пробелы до/после ключа
3. Попробуйте скопировать/вставить
```
