## Как работает инжектирование меню

1. Пользователь вводит ключ `73D37C08` в LoginActivity
2. Нажимает кнопку "СТАРТ"
3. MainActivity проверяет наличие com.axlebolt.standoff2:
   - Через PackageManager.getLaunchIntentForPackage()
   - Если не найдено, проверяет через PackageManager.getPackageInfo()
4. Запускает SO2 одним из методов:
   - Через стандартный Launch Intent
   - Через явный Intent на MainActivity SO2
5. Запускает Menu Service который создает overlay
6. Нативная библиотека `libtgReward.so` загружается в процесс SO2
7. Библиотека перехватывает OpenGL функции (eglSwapBuffers)
8. В хуке рендерится ImGui меню с красно-черным дизайном
